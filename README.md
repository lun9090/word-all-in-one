# 📄 办公助手

**Word 报告排版 VSTO 插件** —— 一键实现报告格式标准，大幅提升文档处理效率。

---

## ✨ 主要功能

| 功能类别 | 具体操作 | 快捷键/按钮 |
|----------|----------|-------------|
| **标题样式** | 方正小标宋、二号、居中，固定行距29磅 | `大标题` |
| **小标题样式** | 方正楷体、三号、居中，无缩进，段前段后0磅，固定行距29磅 | `小标题` |
| **正文样式** | 方正仿宋、三号、两端对齐，段前段后0磅，固定行距29磅 | `正文` |
| **一级标题（黑体）** | 方正黑体 + 自动编号（一、二、…） | `标题一、~标题九、` |
| **二级标题（楷体）** | 方正楷体 + 自动编号（（一）、（二）、…） | `（一）、~（二）、` |
| **三级标题（仿宋）** | 方正仿宋 + 阿拉伯数字编号（1.、2.、…） | `1.~2.` |
| **四级标题（仿宋）** | 方正仿宋 + 括号编号（（1）、（2）、…） | `（1）~（2）` |
| **表格快速排版** | 自动调整列宽、宋体五号、居中、边框、标题行加粗并重复 | `表格`（当前表）<br>`批量表格`（全部表） |
| **页面精细设置** | A4、边距（上37下35左28右26mm）、页脚24.7mm、每页22行网格、禁止标点溢出、修改正文样式使后续段落自动继承 | `页面设置` |
| **标记与颜色** | 黄色高亮 + 红色字体 / 清除标记 | `标黄标红` / `恢复默认` |
| **查找替换** | 删除多余换行符（保留中文标点后一个回车） | `断行重排` |
| **大纲级别** | 一键设置为1~6级，或升降级 | `大纲级别一、~大纲级别六、及大纲升级、大纲降级` |
| **缩进控制** | 首行缩进2字符 / 取消所有缩进 | `缩进` / `顶格` |

## 🚀 快速开始

### 环境要求
- **操作系统**：Windows 7 及以上
- **Office**：Microsoft Office 2010 及以上（支持 Word）
- **.NET Framework**：4.6.1 或更高
- **开发工具**：Visual Studio 2019/2022（含 VSTO 工作负载）

### 安装与使用
1. 下载本仓库源码或 Release 安装包。
2. 运行安装程序（.vsto 或 .msi），插件会自动注册到 Word。
3. 启动 Word，在 **“加载项”** 选项卡中即可看到 **“办公助手”** 功能区，点击相应按钮即可应用样式。

> 💡 **提示**：首次使用建议先点击 `页面设置`（页面设置），让后续所有段落自动继承标点控制和首行缩进；正文段落如需首行缩进2字符，请点击 `缩进`。

## 📐 设计理念

- **忠于规范**：遵循常见公文排版参数（字体、字号、行距、页边距等）。
- **高效批处理**：支持批量处理整个文档的表格、段落和样式。
- **性能优化**：关闭屏幕更新、显式释放 COM 对象，处理百页文档仍保持流畅。
- **易扩展**：代码分层清晰，新增样式或编号只需调用核心方法。

## 🛠️ 技术栈

- **语言**：C#
- **框架**：.NET Framework 4.6.1
- **Office 互操作**：Microsoft.Office.Interop.Word
- **开发模型**：VSTO（Visual Studio Tools for Office）
- **设计模式**：辅助方法封装 COM 操作，资源管理使用 `try-finally` + `Marshal.ReleaseComObject`
